# Организация папки SO Engine

Дата: 2026-07-15

## Итоговая структура

```text
SO Engine/
├── 00_SO_ENGINE_ЗАПУСТИТЬ.lnk   пользовательский лаунчер
├── 01_КАК_ЗАПУСТИТЬ.txt         краткая инструкция
├── archive/                      сохранённые исторические материалы
│   └── batch_refresh/            прежние batch-входы и логи
├── docs/                         документация и CHANGELOG
├── launcher/                     реализация Windows-лаунчера
├── runtime/                      результаты рабочих запусков
├── skill/                        проектный Hermes skill
├── so_engine/                    основной программный пакет
├── tests/                        автоматические тесты
├── .git/ и .venv/                Git и локальное Python-окружение
└── корневые конфигурационные и совместимые файлы
```

## Перемещено

- четыре `test_*.py` → `tests/`;
- `CHANGELOG.md` → `docs/CHANGELOG.md`;
- `batch_refresh/` → `archive/batch_refresh/` без удаления входных файлов и логов;
- `.launcher/` → `launcher/`, ярлык обновлён на новый путь.

## Удалён подтверждённый генерируемый мусор

- `.mypy_cache/`;
- `.pytest_cache/`;
- `.ruff_cache/`;
- корневой и проектные `__pycache__/`;
- `.coverage`;
- `dist/`.

Эти элементы автоматически создаются повторно при разработке и сборке. Пользовательские результаты из `runtime/`, виртуальное окружение `.venv/`, Git, исходники, документация, skill и исторические batch-данные сохранены.

Тесты не удалены: они перенесены в отдельный каталог `tests/`, потому что защищают программу и алгоритм расчёта от поломок.

## Проверка

- launcher self-test должен вернуть `SELF-TEST: OK`;
- полный project verifier должен вернуть `SO ENGINE VERIFICATION: PASS`;
- `so_engine/selector.py` не должен изменяться.
